# BI Analyst Course Project

A comprehensive Business Intelligence course project featuring data analysis, business requirements documentation, and an interactive analytics dashboard.

## 📊 Project Overview

This repository contains a complete BI Analyst course project that demonstrates the end-to-end process of business intelligence implementation, from requirements gathering to dashboard development and data visualization.

### Key Components

- **Business Requirements Document (BRD)**: Detailed documentation of project scope, objectives, and functional requirements
- **Interactive Dashboard**: Live analytics dashboard built with Google Looker Studio for data visualization and insights
- **Data Analysis**: Business intelligence analysis and reporting

## 🎯 Dashboard

The project features an interactive dashboard accessible here:

🔗 **[View Live Dashboard](https://lookerstudio.google.com/s/mZJvRs2-3FQ)**

This dashboard provides:
- Real-time data visualization
- Key performance indicators (KPIs)
- Interactive filters and drill-down capabilities
- Business metrics and analytics insights

### Dashboard Preview

The dashboard enables users with minimal technical experience to:
- View data through intuitive visual representations (charts, graphs, tables)
- Filter data by date ranges, categories, and other dimensions
- Monitor business performance metrics
- Generate insights from data at a glance

## 🚀 Getting Started

### Viewing the Dashboard
1. Click the link in `Link Dashboard.txt` or access it directly: [Looker Studio Dashboard](https://lookerstudio.google.com/s/mZJvRs2-3FQ)
2. No installation or technical setup required
3. Dashboard is accessible through any modern web browser

### Accessing Project Documentation
1. Review the Business Requirements Document (BRD) in either Word (.docx) or PDF format
2. Understand the project scope, data sources, and dashboard specifications
3. Follow the documented requirements for implementation details
